A simple bot to automatically buy Target items.

A few rules:
- Everything you need should be in this folder (the files you see above).
- To download, click the green `<> Code` button and download .zip.
- Enter the required information in the `info.json` file IN THE `dist` FOLDER, not the main folder (unless you know what you're doing).
- A Target account is needed. Make sure to remove all saved payment information on the account. Ideally, a brand-new Target account will probably work best.
- Run the .exe to use this (in the `dist` folder).

Disclaimer: this might wont work the first time. Let me know of any issues.
